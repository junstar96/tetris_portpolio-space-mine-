# 테트리스 (Tetris) 🎮

클래식 테트리스 게임 — Python 백엔드 + HTML5 Canvas 프론트엔드

![Python](https://img.shields.io/badge/Python-3.x-blue)
![HTML5](https://img.shields.io/badge/HTML5-Canvas-orange)
![JavaScript](https://img.shields.io/badge/JavaScript-ES6-yellow)

## 실행 방법

```bash
python3 server.py
```

브라우저에서 `http://localhost:3000` 접속

## 게임 화면

### 메인 메뉴
- **게임 시작** — 테트리스 게임을 시작합니다
- **스코어** — 상위 10위 기록을 확인합니다
- **게임 종료** — 종료 화면으로 이동합니다

### 게임 플레이
| 위치 | 내용 |
|------|------|
| 중앙 | 10×20 테트리스 보드 |
| 좌측 상단 | 점수, 레벨, 라인 수, 플레이 타임(초) |
| 좌측 하단 | 홀드 블록 |
| 우측 상단 | 다음 블록 미리보기 3개 |

## 조작법

| 키 | 동작 |
|----|------|
| ← → | 좌우 이동 |
| ↑ | 회전 |
| ↓ | 소프트 드롭 |
| Space | 하드 드롭 (즉시 착지) |
| C / Shift | 홀드 |
| P / ESC | 일시정지 |

## 게임 기능

- **7-bag 랜덤 시스템** — 공정한 블록 배분
- **고스트 피스** — 착지 위치 미리보기
- **벽 차기(Wall Kick)** — SRS 회전 시스템
- **레벨업** — 10줄 클리어마다 속도 증가
- **라인 클리어 애니메이션** — 플래시 이펙트
- **스코어 저장** — 서버 Top 10 리더보드
- **벨트스크롤 배경** — 위→아래로 내려가는 테마 배경 (아래 참고)

## 로그라이크 모드

메뉴의 **🗺️ 로그라이크 모드**로 시작합니다. `roadmap` 지도 위에서 맨 위(START 육각형)부터 맨 아래(GOAL 링)까지 경로를 골라 내려갑니다.

- **경로 규칙**: 매 판 무작위 생성. START→GOAL의 모든 경로는 **최단 8~9칸, 최장 11~12칸**을 유지합니다 (생성 후 검증, 교차하는 선 없음).
- **칸 종류**
  | 아이콘 | 칸 | 내용 |
  |---|---|---|
  | ? | 이벤트 | 포인트를 사용하는 선택지 이벤트 (현재: 자격증 시험일) |
  | ⛏ | 광산 | Jewel Mine 배경 테트리스, 목표 줄 수 제거 시 클리어 |
  | ☠ | 해적선 | Space 배경 테트리스, 해적선 격추 시 현상금 |
- **포인트**: 시작 포인트(3,000 P) + 스테이지에서 얻은 점수가 누적되어 이벤트에 사용됩니다.
- **이벤트 선택지 버튼**: 🔵 파랑 = 선택 가능 / 🔴 빨강 = 포인트 부족 / ⚫ 검정 = 그 외 조건 불충족. 버튼 위에 자격증 이름과 비용/사유 문구가 표시됩니다.
- **자격증 시험일 이벤트**: 현상금 사냥꾼(bounty_hunter) · 보석 감별사(gem) · 채굴사(mining) · 수리공(repair) × 브론즈/실버/골드/플래티넘. 비용 1,000 / 5,000 / 10,000 / 50,000 P. 한 번 방문에 하나만 응시할 수 있고, 다음 등급만 응시 가능합니다.
- 구현: `static/roguelike.js`, 에셋 `static/roguelike/` (roadmap, 버튼 3종, 이벤트 패널, 자격증 16종)

## 벨트스크롤 배경

| 모드 | 테마 | 이미지 |
|------|------|--------|
| 파이렛 (데스크톱/모바일) | Space Open-Pit Mine | `backgrounds/space_1~4.webp` |
| 라이징 | Jewel Mine | `backgrounds/jewel_1~4.webp` |

- 4장의 이미지가 1 → 2 → 3 → 4 순서로 세로로 이어 붙어 카메라가 위에서 아래로 내려갑니다.
- 스크롤 속도는 레벨별 게임 속도(낙하 간격 `800 - (level-1)*60`ms)에 비례합니다.
- 1~9레벨 구간 길이는 각 레벨의 속도 비율로 나누어지며, 9레벨까지는 끝 직전(97%)에서 멈추고
  **10레벨 도달 시 4번 이미지 맨 아래에 도착**해 이후로는 더 이상 움직이지 않습니다.
- 레벨업이 예상보다 빠르면 카메라가 부드럽게 따라잡고, 레벨이 오래 지속되면 구간 끝에서 감속·정지합니다.
- 구현: `static/bg-scroller.js` (데스크톱 `tetris.js`와 모바일 `mobile.js`에서 공용 사용)

## 프로젝트 구조

```
├── server.py              # Python HTTP 서버 (포트 3000)
├── static/
│   ├── index.html         # 게임 HTML (메뉴, 게임, 스코어 화면)
│   ├── style.css          # 다크 테마 UI 스타일
│   ├── tetris.js          # 테트리스 게임 엔진
│   ├── bg-scroller.js     # 벨트스크롤 배경 (jewel / space 테마)
│   ├── roguelike.js       # 로그라이크 모드 (지도 생성, 이벤트, 스테이지)
│   ├── roguelike/         # 로그라이크 에셋 (roadmap, 버튼, 이벤트, 자격증)
│   ├── backgrounds/       # 배경 이미지 (jewel_1~4, space_1~4 .webp)
│   └── favicon.ico        # 파비콘
├── .gitignore
└── README.md
```

## 기술 스택

- **백엔드**: Python 3 (`http.server` 표준 라이브러리)
- **프론트엔드**: HTML5 Canvas, CSS3, Vanilla JavaScript
- **폰트**: Press Start 2P (레트로), Noto Sans KR (한글)
- **데이터**: JSON 파일 기반 스코어 저장
